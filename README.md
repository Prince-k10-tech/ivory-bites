# IvoryBites — GitHub Pages deployment

This repository is the static website build for IvoryBites Restaurant and Bakery.

## Publish with GitHub Pages
1. Create a **public** repository named `ivorybites`.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. GitHub will show the published URL in the Pages section after deployment finishes.

## Important
This is currently a demonstration build. The site intentionally has `noindex` metadata and a crawler-blocking `robots.txt`. Do not remove those until the business approves the content and provides its real domain and required confirmations.

The public business details, menu samples, hours, review figures, and demo notice should be confirmed with the business before production launch. Contact links use WhatsApp; forms do not store submissions.

For a custom domain, update the central source configuration and rebuild before launch. This deployment package contains the generated static site only.
